# Сайт «Audi S8 D5» 🏁

Готовый одностраничный сайт про Audi S8 поколения D5 (модельный 2023 год, рестайлинг):
характеристики 4.0 V8 TFSI, таймлайн всех поколений S8 от D2 до рестайлинга,
технологии (прогнозирующая активная подвеска, подруливающая задняя ось),
дизайн и салон, интересные факты и конкуренты. Тёмный дизайн в стиле Audi Sport,
без внешних зависимостей (шрифты, картинки и библиотеки не нужны — работает офлайн).

## Как открыть

Достаточно двойного щелчка по `index.html` — сайт откроется в браузере.
Для красивого адреса можно поднять локальный сервер:

```bat
python -m http.server 8000 --directory .
```

и открыть http://127.0.0.1:8000

## Как опубликовать в интернете (бесплатно)

- **GitHub Pages** — создайте репозиторий, загрузите файлы, включите Pages в настройках.
- **Netlify / Vercel** — перетащите папку с сайтом в форму загрузки на сайте — получите ссылку через минуту.

## Структура

```
index.html      — разметка страницы
css/style.css   — стили (тёмная тема, адаптивность)
js/script.js    — меню, вкладки, анимации счётчиков и появления
```
